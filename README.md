==================================================
        FAKE ROBUX NUMBER CHANGER - SETUP
==================================================

OVERVIEW:
This repository/folder contains a web landing page and a 
downloadable Chrome browser extension package designed to 
locally customize the displayed Robux counter on roblox.com.

FILE STRUCTURE:
- index.html           : Main website landing page
- style.css            : Website styling stylesheet
- RobuxCustomizer.zip  : Compressed extension package ready for download
- README.txt           : Documentation and setup guide

--------------------------------------------------
HOW TO HOST THE WEBSITE:
--------------------------------------------------
1. Upload all contents of this folder (index.html, style.css, 
   RobuxCustomizer.zip, README.txt) to your web host 
   (e.g., GitHub Pages, Netlify, or Vercel).
2. Ensure RobuxCustomizer.zip remains in the same directory 
   as index.html so the download link functions correctly.

--------------------------------------------------
USER INSTALLATION INSTRUCTIONS (FOR YOUR VISITORS):
--------------------------------------------------
1. Download RobuxCustomizer.zip from the website.
2. Right-click RobuxCustomizer.zip and choose "Extract All".
3. Open Chrome, Edge, or Brave and navigate to:
   chrome://extensions/
4. Enable "Developer mode" using the toggle in the top-right corner.
5. Click "Load unpacked" in the top-left corner and select 
   the extracted extension folder.
6. Navigate to roblox.com, click the extension icon in your toolbar, 
   type your custom number, and click "Apply Change".

--------------------------------------------------
NOTE:
This extension operates purely on client-side DOM elements.
Changes exist only within the local browser session.
